# Pashu-Rakshak AI — Complete Frontend Demo

This ZIP contains a runnable React/Vite frontend based on the uploaded **PASHU-RAKSHAK AI 10/10 Complete Website Master Blueprint**.

## Included
- Login/demo login
- Dashboard with Health Pulse, stats, alerts, map, cases and trend
- Animals and risk/health cards
- AI Disease Detection demo workflow
- Disease Surveillance Map
- Alerts / Early Warning
- Health Records
- Veterinarian
- Laboratory
- Vaccination
- Treatment
- Case Management
- Outbreak Management
- Analytics
- Government/Admin
- Profile & Settings
- Help & Support
- Responsive desktop/mobile layout
- English/Hindi toggle demo
- Simulated AI clearly labeled as simulated

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

This is a frontend/demo implementation. A real backend/database, real map provider and real AI API should be connected later as described in the blueprint.
